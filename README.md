## 它能帮你做什么？

跑 AI 编程任务时，不用一直盯着终端。工具检测到需要授权、等待答复或任务结束，就把任务名称和当前信息推送到你的设备上。收到授权提醒后，回到电脑确认，任务即可继续。

它也可以作为你自己的 **电脑消息推送入口**。预留的本机接口可供脚本、程序或 Agent 调用：你决定“什么值得提醒”，工具负责排队、去重、重试和推送。

| 使用场景 | 收到的消息 | 接入方式 |
| --- | --- | --- |
| Codex 编程任务 | 授权、等待答复、完成或中断 | 内置适配，支持范围见下表 |
| DeepSeek Harness 任务 | 授权、完成、失败或中断 | 内置 DSH 日志适配 |
| 下载、备份、批处理 | 下载完成、备份失败、处理结果 | 自定义脚本调用接口 |
| 股价或指标监测 | 达到你设定的阈值时提醒 | 自行接入数据和判断逻辑 |
| 电脑、浏览器或网站监测 | 你关心的状态变化 | 编写脚本，也可让 Agent 帮你完成 |

> 系统消息、浏览器监测等属于 **DIY 接入场景**。工具提供推送接口，未内置行情订阅，也不会自动截获全部 Windows 通知。

## 三步开始使用

1. 在 [Releases](https://github.com/cleverbo01/harmony-device-push/releases) 下载 **完整运行 ZIP**，解压到可写目录。
2. 双击 **鸿蒙设备信息推送工具.exe**，在右上角“推送设置”填写自己的 **MeoW 设备 ID**，保存。
3. 点击 **“刷新并开始监控”**，发送一次“测试推送”，确认设备能收到消息。

完整运行包附带 Node，**无需另装 Node，也不用打开 CMD**。请完整解压，不要只取 EXE 或从压缩包内运行。系统需具备 .NET Framework 4.x。

若 Releases 暂未提供运行包，或你使用 Git 克隆源码，可运行 `获取运行时.ps1` 准备 Node，再打开 EXE。

## 哪些任务能自动提醒？

工具自动寻找本机 Codex CLI、共享服务、桌面版安装及本地任务记录，并读取用户目录下的 DSH 日志。界面会标出当前接入方式。

| 来源 | 授权 / 等待答复 | 任务结束提醒 |
| --- | --- | --- |
| Codex CLI，可连接的共享服务 | 支持授权、等待答复 | 完成、失败、中断 |
| Codex 独立 CLI（`--no-daemon`） | 暂不支持 | 本地记录中的完成、中断 |
| Codex 桌面版，仅有独立 stdio 通道时 | 暂不支持直接订阅 | 本地记录中的完成、中断 |
| DSH / DeepSeek Harness | 支持明确的日志授权事件 | 完成、失败、中断 |

DSH 当前适配 v3/v4 会话日志。不同版本、非默认数据目录或接口变化可能需要调整，详见[使用文档](使用文档.md)。工具发送授权提醒，**不会代替你批准操作**。

## 想看哪些、想推哪些，都可以选

- **三个任务卡片**：分别选择对话，也可以留白。切换显示不影响其他任务的推送。
- **单独静音任务**：例如五个 Codex 任务，只关闭其中一个的“推送此任务”。
- **关闭整个来源**：在设置里关闭 Codex、DSH 或 DIY 的推送。
- **最新信息优先**：展示最新摘要，长内容按空间截取；通过下拉菜单查看历史。
- **推送时间可见**：对应的最新消息旁显示“HH:mm:ss 已推送”，下方保留运行和推送日志。

任务状态与监听状态分开显示：**执行中绿色、等待授权橙色、完成蓝色、异常红色；未监控标记灰色**。停止监听后保留最后检测状态，并注明“上次”。

静音仍保留任务显示，会取消尚未发送的通知；重新开启只推送新事件，不补发静音期间的消息。已提交的请求无法撤回。



## 让 Agent 帮你做 DIY

不必修改主程序。把需求和[Agent DIY 接入指南](agent-DIY接入指南.md)交给编程 Agent，让它写一个独立脚本即可。例如：

> 请读取这个工具的“agent-DIY接入指南.md”和“接入接口说明.md”，帮我写一个下载完成提醒脚本。通过现有本机接口推送，用稳定事件 ID 防止重复提醒，先用样例数据验证。不要打印接口 token。

**你的程序发现事件 → 本机推送接口 → 持久化队列 → MeoW → 设备提醒**

默认接口：`POST http://127.0.0.1:17863/api/push`，可指定来源、事件 ID、标题、正文和状态。Node/Python 客户端会自动读取本机端口和 token。

开始监控后，在工具目录试一条通知：

```powershell
& .\runtime\node.exe .\接口示例\发送通知.mjs "下载完成" "文件已保存，可以查看了。" "下载任务" "download-001" "completed"
```

相同来源和事件 ID 会去重，发送失败会退避重试。接口排队成功不等于设备已显示；详细返回值与调用方式见[接入接口说明](接入接口说明.md)。

## 数据与使用范围

- 配置、接口 token、任务状态和日志保存在你自己的电脑。首次生成独立配置和随机 token；发行包不含作者的设备 ID、凭据或任务记录。
- 推送的任务名称与正文摘要通过 HTTPS 发送给 **api.chuckfang.com 的 MeoW 服务**，再由该服务投递到设备。需要可用的设备 ID 和网络连接。
- 接口仅监听 `127.0.0.1`，要求 Bearer token。不要分享使用后的 `config.json`、`运行记录/` 或备份；仓库已通过 `.gitignore` 排除这些文件。
- 当前已有 13 项自动测试及 Windows 桌面自检，尚未覆盖所有 Codex/DSH 版本或在第二台实体电脑验证。实际投递请用测试推送和真实任务确认。
